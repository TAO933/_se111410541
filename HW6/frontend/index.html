🐳 MicroDocker 微服務展示系統

Nginx 反向代理 + Node.js + Python + Rust + PostgreSQL —— 全部跑在 Docker 裡

http://localhost:8080 → nginx → 各微服務

🏗 系統架構

Browser (:8080)
     │
     ▼
┌─────────────┐     ┌──────────────┐
│   nginx     │────▶│   frontend   │  (nginx:alpine 靜態頁, 就是本頁)
│ reverse-proxy│     └──────────────┘
│  :80        │────▶ /api/node/   → api-node:3001    (Node.js + Express + pg)
│             │────▶ /api/python/ → api-python:5000  (Python + Flask + psycopg2)
│             │────▶ /api/rust/   → api-rust:8000    (Rust + Axum)
└─────────────┘           │            │
                          └────▶ postgres:5432 (postgres:16-alpine + volume pgdata)
    全部在同一個 bridge network「micronet」內，用 service name 當 DNS 互連
