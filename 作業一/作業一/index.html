作業一

ym_curl.py

以 Python 打造的輕量級命令列工具，支援基本 curl 請求，並內建中華職棒戰績爬取與圖表視覺化功能。

專案簡介

本專案以 Python 為核心，實作一個簡易的 curl 替代工具。除了一般的 HTTP 請求功能外，更進一步整合了中華職棒 CPBL 官方網站的戰績爬取與視覺化圖表，讓工具兼具實用性與趣味性。

圖表功能則借助 matplotlib 與 beautifulsoup4 兩個第三方套件完成，分別負責圖表繪製與 HTML 解析。

使用方式

① 抓取網頁原始碼

# 基本網頁抓取
py ym_curl.py https://example.com

②送出 POST 資料

py ym_curl.py -X POST -d "name=ccc&msg=hello" https://example.com/api

③ 查看中華職棒戰績

py ym_curl.py --cpbl

# 輸出範例：
======================================================================
中華職棒 2026 下半季戰績
======================================================================
排名 球隊 出賽 勝 和 敗 勝率 勝差
----------------------------------------------------------------------
1 樂天桃猿 33 18 0 15 0.545 -
2 中信兄弟 37 20 0 17 0.541 0
3 味全龍 35 18 0 17 0.514 1

5 台鋼雄鷹 34 16 0 18 0.471 2.5
6 富邦悍將 35 15 0 20 0.429 4

④ 產生戰績圖表

py ym_curl.py --cpbl --chart

# 會產生兩個圖檔：

專案檔案結構

檔案 用途
ym_curl.py 主程式：curl 功能 + CPBL 戰績爬取 + 圖表生成
cpbl_standings_chart.png 四合一戰績分析圖（勝敗場數、勝率排名、勝差分佈、雷達圖）
cpbl_winrate_ranking.png 各隊勝率排名獨立大圖

所需套件

本工具使用以下第三方套件（CPBL 功能所需）：

py -m pip install beautifulsoup4 matplotlib
套件 用途
beautifulsoup4 解析 CPBL 官網 HTML，提取戰績表格資料
matplotlib 繪製戰績長條圖、勝率排名圖、圓餅圖、雷達圖

原始碼重點

  • SSL 安全：透過 ssl.create_default_context() 與 HTTPSHandler 確保 HTTPS 連線安全。
  • CPBL 爬蟲：使用 BeautifulSoup 解析 cpbl.com.tw 的 HTML 表格，並以正則備援方案確保容錯。
  • 圖表生成：以 matplotlib 繪製四種圖表，自動偵測系統中文字型，確保中文正常顯示。
  • 隊伍配色：依據各隊官方色彩設定對應顏色，提升圖表辨識度。
