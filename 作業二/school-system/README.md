# 🎓 校務系統

前端單檔 `index.html`＋ Node 零依賴後端＋ SQLite，資料存 `db/school.db`（8 張表），不再用瀏覽器 `localStorage`。
支援一鍵還原展示資料。

## 快速開始

1. `node db/seed.mjs` 建立 `db/school.db`
2. `node db/server.mjs` 啟動後端，開 `http://127.0.0.1:3001/`
3. 選擇身分頁籤（學生 / 老師 / 管理員），輸入帳號密碼登入（打 `POST /api/login`）
4. 登入頁有「⚡快速登入」按鈕，可一鍵切換展示帳號
5. 右上角「↺ 還原展示資料」可隨時重置回初始種子資料（`POST /api/db` 整庫覆寫）

| 🏅 獎懲與操行 | 操行成績、各類獎懲次數統計、獎懲明細（日期、類別、事由、登錄人） |

## 核心規則

- **學期成績換算**：平時 × 30%＋期中 × 30%＋期末 × 40%，四捨五入取整數
- **GPA 對照**：90+ → 4.3；85+ → 4.0；80+ → 3.7；77+ → 3.3；73+ → 3.0；70+ → 2.7；67+ → 2.3；63+ → 2.0；60+ → 1.7；未滿 60 → 0
- **操行成績**：基點 85，嘉獎 +1、小功 +2.5、大功 +7.5、警告 −1、小過 −2.5、大過 −7.5，結果限制 0–100 分
- **請假流程**：學生送出（待審核）→ 導師通過 / 退回 → 通過時自動在出缺席產生當天各課「請假」紀錄（備註「請假申請通過」），已有同日同課紀錄則跳過不重複
- **課程排名**：同門課中有公布學期成績者才納入排序
- **選課限制**：學分上限 25、同時間課程跳出衝堂確認、額滿不可加選

## 程式架構

全系統收錄於單一 `index.html`（HTML＋CSS＋JavaScript，無外部依賴、無框架）：

```
school-system/
├── index.html   # 系統本體（畫面＋邏輯＋種子資料）
└── README.md    # 本說明文件
```

| 區塊 | 說明 |
|---|---|
| `<style>` | 版面樣式：登入卡片、頂欄＋側欄主版面、卡片、表格、徽章（pill）、課表格線、彈窗 |
| 資料層 | `seedDB()` 種子資料、`saveDB()` / `loadDB()` 走 `GET/POST /api/db` 整庫讀寫 SQLite、`resetDB()` 一鍵還原 |
| 工具函式 | `esc()` 防 XSS 跳脫、`gradeOf()` 取成績、`calcSem()` 學期成績換算、`rankOf()` 排名、`conductOf()` 操行計算、`leavePill()` / `rewardPill()` / `gradePill()` / `statusPill()` 狀態徽章 |
| 登入 | `doLogin()`（帳密＋身分頁籤雙重驗證）、`quick()` 快速登入、`enterApp()` / `logout()` |
| 路由 | `buildNav()` 依身分產生側欄、`go()` 切換、`render()` 按 `curView` 渲染對應視圖函式並填入表格 |
| 視圖函式 | `vAnnounce`、`vCourseCenter`、`vTimetable`、`vGrade`、`vStudentAtt`、`vProfile`、`vLeaveStudent`、`vConductStudent`、`vTeacherCourses`、`vLeaveReview`、`vRewardManage`、`vAdminUsers`、`vAdminCourses`，搭配 `openModal()` 彈窗表單 |
| 啟動 | `loadDB(); renderDemo();` |

## 資料模型

存於 `db/school.db` 的 SQLite 資料庫（後端 `db/server.mjs` 提供 `GET/POST /api/db` 整庫讀寫）：

- **users**：`{id, account, password, role(student/teacher/admin), name, dept, email, phone, birthday, address, advisorId(學生導師)}`
- **courses**：`{id, code, name, teacherId, credits, semester, time(例「週一 09:00-12:00」), room, capacity, desc}`
- **enrollments**：`{studentId, courseId}` 選課關係
- **grades**：`{studentId, courseId, regular(平時), midterm(期中), final(期末), score(學期成績)}`
- **attendance**：`{id, studentId, courseId, date, status(出席/遲到/缺席/請假), note}`
- **leaves**：`{id, studentId, date, reason, status(待審核/通過/退回), applyDate, reviewer, reviewNote}`
- **announcements**：`{id, title, content, authorId, authorName, date, pinned}`

## 常見操作

- **新增學生/老師**：管理員 → 帳號管理 →「新增帳號」，學生記得指派導師
- **開新課程**：管理員 → 課程總覽 →「新增課程」，時間格式請用「週X HH:MM-HH:MM」以便課表解析
- **登錄成績**：老師 → 授課課程 → 選課 →「學生成績」頁籤，填完三欄按儲存
- **審假**：老師 → 請假審核 → 通過 / 退回（通過自動寫入出缺席）
- **記獎懲**：老師 → 獎懲管理 → 選學生＋類別＋事由 → 登錄
- **資料亂了**：頂欄「↺ 還原展示資料」回到初始狀態
